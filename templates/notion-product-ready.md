# Solo AI System — Templates Notion Prontos para Uso

Este é o produto final: 3 templates prontos para copiar e colar no Notion como páginas completas. Eles já vêm com:

- estrutura de páginas e seções
- blocos de instrução prontos
- toggles para preencher dados
- tabelas e calendários de uso real
- textos modelo para usar imediatamente

## 1) Página: 📋 Gerador de Propostas para Clientes

### Instruções principais
> ⚡ COMO USAR ESTE TEMPLATE
> 1. Preencha os campos do cliente.
> 2. Use a proposta modelo pronta abaixo.
> 3. Substitua os campos entre colchetes.
> 4. Envie ao cliente.

### ✏️ Passo 1 — Dados do Cliente
- Toggle: 👤 Nome do cliente
  - Exemplo: "Maria García / Estúdio MG"
- Toggle: 💬 Problema principal
  - Exemplo: "Site não converte visitantes em clientes"
- Toggle: 🛠 Meu serviço
  - Exemplo: "Copy estratégica para 5 páginas de site + revisão"
- Toggle: 💵 Meu preço
  - Exemplo: "R$ 1.200" ou "R$ 800–R$ 1.500"
- Toggle: 📆 Prazo de entrega
  - Exemplo: "10 dias úteis"

### ✅ Seção: Proposta pronta
Use este texto como proposta final. Basta substituir os colchetes com as informações do cliente.

```
Olá [Nome do cliente],

Entendo que [problema principal]. Estou preparado para resolver isso com uma proposta clara, rápida e direcionada ao seu negócio.

O que vou entregar:
• Copy para a homepage
• Copy para página de serviços
• Copy para página «Sobre»
• Revisão e ajustes finais

Como funciona:
1. Brief inicial com você
2. Eu preparo a primeira versão
3. Revisão e ajustes até sua aprovação

PRAZO: [prazo de entrega]
INVESTIMENTO: [meu preço]

Este valor garante uma entrega profissional, com foco em conversão e posicionamento de marca.

Se quiser, posso enviar uma versão customizada com pontos de diferenciação para o seu público.

Fico à disposição,
[Seu nome]
```

### 📁 Base de dados — Histórico de Propostas
Crie uma tabela com estas colunas:
- 👤 Cliente (Title)
- 🛠 Serviço (Text)
- 💵 Preço (Number, formato $)
- 📊 Status (Select): Enviada, Negociando, Fechada, Perdida
- 📅 Data (Date)
- 📝 Notas (Text)

### Modelo de uso
- Crie um novo item por cliente
- Atualize o status conforme negocia
- Salve os aprendizados em Notas

## 2) Página: 📅 Planejador de Conteúdo Semanal

### Instruções principais
> 🚀 Use este template para gerar sua semana de conteúdo sem abrir página em branco.
> Preencha seu perfil uma vez e o restante fica pronto.

### ⚙️ Meu Perfil de Conteúdo (só preencher uma vez)
- Toggle: 🎯 Meu nicho
  - Exemplo: "Sistema IA para solopreneurs"
- Toggle: 👥 Minha audiência
  - Exemplo: "Empreendedores solo que querem vender mais"
- Toggle: 📱 Plataforma principal
  - Exemplo: "Instagram"
- Toggle: 🗣 Meu tom de voz
  - Exemplo: "Direto, claro e motivador"
- Toggle: 🏁 Minha oferta
  - Exemplo: "Sistema AI com templates de venda"

### 📆 Planejamento semanal pronto
Crie um calendário no Notion com estas colunas:
- 📝 Post / Título (Title)
- 📱 Plataforma (Select): Instagram, LinkedIn, TikTok, YouTube
- 🏷 Tipo (Select): Educativo, Dica, História, Promo, Engajamento
- 📊 Status (Select): Rascunho, Pronto, Programado, Publicado
- 📅 Data (Date)
- 📄 Caption completo (Text)
- #️⃣ Hashtags (Text)

### Modelo de posts para copiar
#### Segunda — Educativo
**Hook:** "3 erros que estão matando sua conversão online"
**Caption:**
- Erro 1: copy genérica
- Erro 2: oferta fraca
- Erro 3: falta de prova social
**CTA:** "Salva para revisar seu site depois"
**Hashtags:** #marketingdigital #copywriting #soloai

#### Terça — Dica
**Hook:** "Use este curso para vender mais todos os dias"
**Caption:**
- Fale do que seu cliente realmente sente
- Mostre resultado rápido
- Termine com benefício claro
**CTA:** "Comenta se você já usa isso"

#### Quarta — História
**Hook:** "Como eu transformei um lead frio em venda em 24h"
**Caption:**
- Contexto real
- O problema do cliente
- A solução que entreguei
- Resultado final
**CTA:** "Conta sua história nos comentários"

#### Quinta — Educativo
**Hook:** "Por que sua página de vendas não vende"
**Caption:**
- Verifique clareza da oferta
- Tenha prova social forte
- Evite descrições vagas
**CTA:** "Quer um checklist?" 

#### Sexta — Bastidores / Prova social
**Hook:** "Hoje trabalhei no site da [cliente] e já entreguei..."
**Caption:**
- Mostre processo
- Mostre resultado rápido
- Mostre status real do projeto
**CTA:** "Curte se quiser ver mais bastidores"

#### Sábado — Promo leve
**Hook:** "Ainda há vagas para meu serviço de copy deste mês"
**Caption:**
- O que está incluso
- Quem deve aplicar
- Deadline suave
**CTA:** "Me chama no direct se quiser" 

#### Domingo — Engajamento
**Hook:** "Qual seu maior bloqueio para criar posts?"
**Caption:**
- Faça 1 pergunta aberta
- Dê 1 exemplo pessoal
- Convide a responder
**CTA:** "Comenta abaixo"

### Extra: modelo de calendário
- Segunda: Educativo
- Terça: Dica
- Quarta: História
- Quinta: Educativo profundo
- Sexta: Bastidores / prova social
- Sábado: Promo leve

## 3) Página: 🧠 Dashboard Diário do CEO

### Instruções principais
> Comece cada manhã com clareza. Esse dashboard já tem tudo pronto para você preencher e seguir.

### 📝 Passo 1 — Brain Dump Diário
- Toggle: 🎯 Meu objetivo #1 de hoje
- Toggle: 📋 Tudo pendente hoje
- Toggle: ⏰ Horas focadas disponíveis
- Toggle: 🔋 Nível de energia agora
- Toggle: ⚠️ Urgências ou bloqueios

### 🤖 Passo 2 — Plano do Dia pronto
Use este texto como plano diário já preenchido com estrutura pronta:

```
1. PRIORIDADES DO DIA
- [ ] Prioridade 1: [tarefa mais importante]
- [ ] Prioridade 2: [segunda tarefa]
- [ ] Prioridade 3: [terceira tarefa]

2. HORÁRIO EM BLOCOS
- 09h00–10h30: [prioridade 1]
- 10h30–11h00: Pausa
- 11h00–12h30: [prioridade 2]
- 12h30–13h30: Almoço
- 13h30–15h00: [prioridade 3]
- 15h00–15h15: Pausa rápida
- 15h15–16h00: Tarefa extra / revisão

3. DIFERIDOS PARA AMANHÃ
- [ ] [tarefa que ficou para depois]

4. IGNORAR HOJE
- [ ] [algo sem impacto do dia]

5. FRASE DE FOCO
- "Hoje vou entregar [resultado] com clareza e foco."
```

### ✅ Seção de Tarefas do Dia
Crie um bloco To-do com 3 itens principais:
- 🔴 Prioridade 1 — [tarefa #1]
- 🟠 Prioridade 2 — [tarefa #2]
- 🟢 Prioridade 3 — [tarefa #3]

### 📊 Histórico diário recomendado
Crie uma tabela com estas colunas:
- 📅 Data (Date)
- 🎯 Objetivo atingido (Checkbox)
- ✅ Tarefas concluídas (Number)
- 🔋 Energia (Select): Alto, Médio, Baixo
- ⭐ Nota do dia (Select): 1, 2, 3, 4, 5
- 📝 Notas rápidas (Text)

## Como entregar este produto
1. Faça uma página principal no Notion com os 3 templates listados.
2. Copie cada seção deste arquivo para a página correspondente.
3. Ajuste os nomes das páginas para: 
   - 📋 Gerador de Propostas para Clientes
   - 📅 Planejador de Conteúdo Semanal
   - 🧠 Dashboard Diário do CEO
4. Compartilhe como template ou exporte o workspace.
