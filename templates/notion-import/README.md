# Import Notion - Solo AI System

Estes arquivos Markdown são preparados para importar diretamente no Notion como páginas independentes.

Como usar:
1. Abra o Notion.
2. Crie uma nova página vazia.
3. Clique em "Import" no menu lateral.
4. Selecione "Markdown & CSV".
5. Importe cada arquivo `.md` da pasta `notion-import`.
6. Ajuste os toggles e tabelas conforme necessário.

- `02-planejador-conteudo-semanal.md`
